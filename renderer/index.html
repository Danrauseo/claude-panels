Files and copying

DragSelect text in Claude and let go to copy it. Drag past the edge to keep going. ⌘⇧CCopy Claude's whole last reply ⌥ dragSelect text in the terminal itself, then ⌘C ⌘UAdd file paths to the selected terminal DropDrop files on a terminal to add their paths, or a folder on a new terminal to start there ⌘OChoose a folder to start Claude in

In a new terminal

/nameStart Claude in a saved harness /add nameChoose a folder and save it as a harness /browseChoose a folder /homeStart in your home folder

Inside Claude

@Type @ at the start of a word to list the other terminals. Pick one with ↑ ↓ and ↵, or press esc to close the list. @2Use the session in terminal 2. Claude messages, searches or reads it as needed. ⇧↵New line in your message

In the top bar

ColourEach harness has its own colour, so you can see which one a terminal is in SpinnerShows how many subagents Claude is running. Hover to see what each one is doing. ExpertA past session that knows about your task. Click it to tell Claude to use it. OpenedClaude in one terminal can open another terminal in a harness to help. A notice at the top right tells you. ApprovalWhen another terminal needs your approval or asks you a question, a small card appears in the one you are using. Click a choice to answer it there.
