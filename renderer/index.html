Settings

When Claude creates a file
Type /name in a new terminal to start Claude in one of these folders. You can also add one there with /add name.
You can add options here, for example claude --model opus.
Shows what each terminal is about in its top bar. The app asks Claude's smallest model, Haiku, for a short title, which costs a tiny amount per session. A name you set with /rename is always used instead.
Once a session has had 5 of your messages, the app asks Haiku for a short CV of what it has worked on, and refreshes it as the session grows. A new session can then find the right expert session for a task, read its CV, search its conversation, and only ask it directly when needed. It checks with you before asking a large session that has not been used recently, because that costs more. Writing each CV costs a tiny amount.

Changes to the instruction and the command apply to terminals you open after saving.
